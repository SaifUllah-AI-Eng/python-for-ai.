# 📝 Assignment Tasks

## Task 1 – Install Python

- Download Python from the official Python website.
- Install the latest stable version.
- Ensure that Python is added to the system PATH.

---

## Task 2 – Verify the Installation

Open the terminal or command prompt and verify the installation by checking the installed Python version.

---

## Task 3 – Install Visual Studio Code

- Download Visual Studio Code.
- Complete the installation.
- Enable the recommended installation options.

---

## Task 4 – Install the Python Extension

Inside Visual Studio Code:

- Open the Extensions panel.
- Search for **Python**.
- Install the official Python extension published by **Microsoft**.

---

## Task 5 – Create Your First Python Project

Create the following project structure:

```text
Python-Practice/
│
└── hello.py
```

---

## Task 6 – Write Your First Program

Create a program that displays the following information:

- Your Name
- Your University
- Your Department
- Your City
- Your Favorite Programming Language
- A welcome message

Example:

```text
Name: John Smith
University: ABC University
Department: Computer Science
City: London
Favorite Language: Python

Welcome to the Python Complete Course!
```

---

## Task 7 – Run Your Program

Run your program successfully using:

- The **Run** button in VS Code
- The integrated terminal

Verify that the output matches your expectations.

---

## Task 8 – Organize Your Project

Ensure your project is organized as follows:

```text
Python-Practice/
│
└── hello.py
```
